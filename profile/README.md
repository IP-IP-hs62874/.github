<h2>一、一条计算式</h2>
<p>地址数等于在用店铺数乘独占系数，再加冗余。独占系数按店铺重要程度取：关键店取一，辅助店可取零点五（两店一段）。冗余取总量的两成。</p>
<p>举例：六个关键店、八个辅助店，则六乘一加八乘零点五等于十，冗余两成后约十二段。这个数字比拍脑袋估的靠谱，也便于向老板解释预算。</p>

<h2>二、三种规模的配比</h2>
<p>五个店以内：建议全部一店一址，冗余一段。这个规模谈折扣没意义，稳定优先，成本可控。</p>
<p>五到二十个店：关键店独享，辅助店两店一段，冗余两成。此时可以开始和服务方谈阶梯价。</p>

<h2>三、冗余怎么留</h2>
<p>冗余不是为了多用，而是为了替换。地址会坏，坏了要有备用能立刻顶上。冗余低于一成，遇到连续坏段就会停摆。</p>
<p>冗余也不必是全新的段，可以是上一批替换下来的、评分尚可的段。这类段做备用足够，成本几乎为零。</p>
<h3>什么时候可以共用</h3>
<p>辅助店、非敏感操作、短期项目可以共用。共用的前提是这些店之间本来就没有关联风险，比如不同类目、不同站点、不同运营人。</p>
<h2>四、采购节奏</h2>
<p>不要一次买满。先买六成，跑一个月，按实际使用率补。使用率低于八成，说明估多了；高于九成且经常需要替换，说明估少了。</p>
<p>补货时尽量要求同段或邻近段，便于统一管理。跨太多 ASN 会让台账变复杂，排查时也更费劲。</p>
<h2>四、使用率怎么看</h2>
<p>使用率等于实际在用的地址数除以购买数。低于八成说明买多了，高于九成五且经常需要替换，说明买少了。每月算一次，按结果调整。</p>
<p>使用率不是越高越好。长期接近百分之百，意味着没有冗余，一次坏段就会影响在营店铺。健康的区间在八成五到九成之间。</p>
<h2>五、什么时候该扩容</h2>
<p>三个信号：经常需要临时借用别人的地址、坏段替换要等货、新店开业前发现没地址可用。出现任意一个，就该补货。</p>
<p>扩容时按现有数量的三成补，别一次补一倍。一次补太多，使用率立刻掉到七成以下，钱就压在那了。</p>

<h2>常见问答</h2>
<h3>一个店铺用两个地址行吗？</h3>
<p>答：技术上可以，但没必要。同一店频繁换登录地，反而更容易触发验证。</p>
<h3>地址闲置会浪费吗？</h3>
<p>答：会。闲置地址照样计费，一年下来是一笔不小的支出。按使用率调整，别囤。</p>
<h3>共用地址一定会关联吗？</h3>
<p>答：不一定。关联取决于多因素，地址只是其中之一。但共用确实提高了关联概率，关键店不要冒这个险。</p>
<h3>可以先买共享段再换独享吗？</h3>
<p>答：可以。先用共享段跑通流程，关键店稳定后再换独享，是常见的过渡路径。</p>
